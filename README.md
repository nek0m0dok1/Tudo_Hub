# Tudo Hub 利用ガイド

## 1. このサービスについて

Tudo Hub は、チームごとにアイデアや提案を共有できるコミュニティ型アプリです。  
ログイン後にチームに所属し、チーム内でアイデアを共有することができます。

## 2. 必要なもの

- Node.js
- npm
- ブラウザ
- Discord アカウント（ログインに使用）

## 3. ログイン方法

メイン画面のログインエリアで「Discordでログイン」を押します。  
Discord の認証画面が表示されるので、認証を選択してください。

ログイン後、ユーザー情報とアイコンが表示されます。  
ログイン状態が確認できると、チーム機能を利用できます。

## 4. チームへの参加

##### 新規チームを作成する
- ログイン後、チーム作成ボタンを押す
- チーム名を入力する
- 招待コードが自動生成される
- 「作成する」を押す
- 作成したチームは、自動的にあなたの所属チームとして追加されます。

##### 招待コードでチームに参加する
- 「招待コードで参加」を選択
- 共有された8文字の招待コードを入力
- 「チームに参加」を押す
- 招待コードは大文字小文字を自動で扱うため、通常はそのまま入力できます。

## 5. チーム内でできること

チームを選択すると、そのチームのアイデア一覧が表示されます。

#### 投稿する
チームを選択する  
投稿フォームにタイトルや内容を入力  
送信する  
投稿した内容は、チームの一覧に追加されます。

#### 投稿一覧を見る  
参加中のチームごとにアイデアが表示されます  
投稿した内容は新しい順に並びます  
投稿の更新や再読み込みも可能です

## 6. 画面の見方

画面の基本構成
左側: 投稿やチームのメイン機能
右側: ユーザー情報とログイン状態
上部: アプリタイトル「Tudo Hub」
チーム選択を変更すると、表示されるアイデアも自動的に切り替わります。

## 7. よくあるトラブル

- ログインできない  
Discord 認証画面で拒否していないか確認  
アプリの URL が正常か確認  
一度ブラウザを再読み込みして再試行してください

- チームに入れない  
招待コードが正しいか確認  
コードの前後に余白がないか確認  
既に参加済みのチームではないか確認

- チームが表示されない  
ログイン状態を確認  
所属しているチームがない可能性があります  
新規作成または招待コードで参加してください

## 8. 利用時の注意

招待コードは他人に共有するとチームに参加される可能性があります。  
チームの情報はログイン中のユーザー本人に紐づいています  
不要になったらログアウトを行ってください  

## 9. まとめ

Tudo Hub は、Discord ログインで簡単に開始でき、チームを作成・参加してアイデアを共有するサービスです。  
初めて使う場合は、まずログイン → チーム作成または招待参加 → 投稿 の順に試すとすぐに使い始められます。
